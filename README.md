# Plombier Wavre Urgent (1300)

Site web professionnel pour l'entreprise artisanale **Plombier Wavre Urgent**, spécialisée dans le dépannage de plomberie d'urgence 24h/24, le débouchage haute pression et les installations sanitaires à Wavre et en Brabant Wallon.

## Technologies

- **Framework** : [Astro 5](https://astro.build)
- **Styling** : Tailwind CSS v4 & tokens sur mesure
- **Typographie** : Manrope & Inter
- **SEO** : Balisage Schema.org LocalBusiness / EmergencyService, Core Web Vitals optimisés, zéro dépendance superflue
- **Déploiement** : Vercel

## Structure des Pages

- `/` : Page d'accueil (Hero d'urgence, grille des expertises, tarifs transparents, avis vérifiés, FAQ)
- `/services` : Détail des 6 expertises sanitaires avec grille tarifaire et méthodologie en 4 étapes
- `/locations` : Secteurs d'intervention (Wavre 1300, Limal, Bierges 1301, Ottignies-LLN, Brabant Wallon)
- `/about` : Engagements, agréments officiels (Cerga, VCA, assurances belges) et données légales
- `/contact` : Ligne d'urgence directe, bouton WhatsApp photo et formulaire de devis en ligne

## Commandes

```bash
# Installation des dépendances
npm install

# Démarrer le serveur de développement
npm run dev

# Compiler pour la production
npm run build

# Prévisualiser la version de production
npm run preview
```
